SUMBER menarik data langsung dari feed RSS/press-release resmi milik masing-masing perusahaan. Tidak ada redaksi, editor, atau media pihak ketiga di antaranya — klik judul untuk membaca rilis asli di domain resmi perusahaan. Fetch dilakukan di browser kamu lewat proxy CORS publik (karena sebagian besar newsroom belum mengizinkan fetch langsung dari browser); jika satu proxy gagal, situs otomatis mencoba proxy cadangan. Sumber daftar bisa diedit di berkas index.html, variabel SOURCES. Daftar proyek crypto mencakup mayoritas top ~100 by market cap yang punya blog/newsroom resmi terverifikasi — lihat README untuk catatan soal proyek di luar itu.
